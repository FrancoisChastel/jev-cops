# Code of conduct

Be kind, be direct, assume good faith. Harassment, personal attacks and discrimination
are not tolerated in issues, pull requests or any project space. Maintainers may
remove content or contributors who break this.

Report concerns to francois@chastel.co.

This is a condensed form of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
